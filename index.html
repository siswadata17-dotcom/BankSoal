Pengiriman nilai otomatis ke Google Spreadsheet

Buka Google Drive

Pengaturan Google Spreadsheet

Masukkan URL Google Apps Script Web App untuk menghubungkan form dengan Google Spreadsheet Anda.

Langkah-langkah Memasang Google Apps Script:

  1. Buka dokumen **Google Spreadsheet** Anda.
  2. Klik menu **Ekstensi** > **Apps Script**.
  3. Hapus seluruh kode yang ada, lalu salin dan tempelkan kode Apps Script di bawah ini.
  4. Klik **Simpan** (), lalu klik tombol **Terapkan (Deploy)** > **Deployment baru**.
  5. Pilih jenis deployment **Aplikasi Web (Web App)**.
  6. Atur **Akses (Who has access)** menjadi **Siapa saja (Anyone)**.
  7. Klik **Terapkan**, izinkan akses akun Google Anda, lalu salin **URL Aplikasi Web** dan tempelkan pada kolom URL di atas.
Kode Google Apps Script (`Code.gs`): 
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);

    // Menambahkan baris baru ke Spreadsheet
    sheet.appendRow([
      new Date(),
      data.nama || "",
      data.nis || "",
      data.kelas || "",
      data.matapelajaran || "",
      data.nilai || "",
      data.catatan || ""
    ]);

    return ContentService.createTextOutput(JSON.stringify({ "status": "success", "message": "Data nilai berhasil disimpan" }))
                         .setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({ "status": "error", "message": error.toString() }))
                         .setMimeType(ContentService.MimeType.JSON);
  }
}
